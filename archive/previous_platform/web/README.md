# web/ (planned)

The agentic front end: an AG-UI client (`@ag-ui/client`) showing live runs, tool calls, approvals
and evidence. It is built from the `DesignSystemStudio/` components (read its `INDEX.md`) with the
Graphite Cyan tokens in `DesignSystemStudio/GraphiteCyan/`. Verified evidence and AI text must look
different, and not by colour alone. Nothing is built yet (spec US4, tasks T062–T064).
